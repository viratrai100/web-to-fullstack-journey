## ProChat (Realtime Chat)

Enhanced chat app with Socket.IO and a basic frontend.

### 🚀 How to Run
```bash
cd 10-ProChat
npm install
node index.js
```

Explore realtime messaging features with rooms and events.

- Basic client UI integration

### 🧰 Technology Used
- Node.js
- Express.js
- Socket.IO

### 🔧 How to Run From Scratch
```bash
npm init -y
npm install express socket.io
echo "/* express + socket.io pro chat skeleton */" > index.js
```
