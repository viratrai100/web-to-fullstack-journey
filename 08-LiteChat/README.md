## LiteChat (Socket.IO Demo)

Basic realtime chat using Socket.IO and Express.

### 🚀 How to Run
```bash
cd 08-LiteChat
npm install
node index.js
```

## 🎯 Summary & Purpose
Send and receive messages in realtime via WebSockets.

### 📘 What I Learned
- Creating Socket.IO server and client events
- Broadcasting and rooms basics
- Serving a static client with Express

### 🧰 Technology Used
- Node.js
- Express.js
- Socket.IO

### 🔧 How to Run From Scratch
```bash
npm init -y
npm install express socket.io
echo "/* express + socket.io chat skeleton */" > index.js
```
