## Bookify (React + Firebase)

Vite + React app using Firebase for auth and data storage.

### 🚀 How to Run
```bash
cd 06-Firebase/09-Bookify/bookify
npm install
npm run dev
# build & preview
npm run build
npm run preview
```

## 🎯 Summary & Purpose
Build a small app with login and basic pages using Firebase services.

### 📘 What I Learned
- Organizing components, pages, and context
- Integrating Firebase auth and Firestore
- Protected routes and simple UI flows

### 🧰 Technology Used
- React, Vite
- Firebase (Auth, Firestore)
- React Router, React Bootstrap

### 🔧 How to Run From Scratch
```bash
npm create vite@latest bookify -- --template react
cd bookify
npm install firebase react-router-dom react-bootstrap bootstrap
# add Firebase config, context, and pages
npm run dev
```
