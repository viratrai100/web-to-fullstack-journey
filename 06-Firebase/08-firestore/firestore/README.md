## 🎯 Summary & Purpose
Create, read, update, and delete documents in Firestore.

### 📘 What I Learned
- Initializing Firestore
- Adding, querying, and updating documents
- Real-time snapshots with listeners

### 🧰 Technology Used
- React, Vite
- Firebase Firestore

### 🔧 How to Run From Scratch
```bash
npm create vite@latest firestore -- --template react
cd firestore
npm install firebase
# use getFirestore, collection, addDoc, getDocs
npm run dev
```
