## React + Firebase: Context API

Share Firebase auth/data via React Context across the app.

### 🚀 How to Run
```bash
cd 06-Firebase/06-contextapi/contextapi
npm install
npm run dev
# build & preview
npm run build
npm run preview
```

## 🎯 Summary & Purpose
Provide Firebase auth and utilities to components via Context.

### 📘 What I Learned
- Creating a context provider
- Exposing auth state and actions
- Consuming context in components

### 🧰 Technology Used
- React, Vite
- Firebase Web SDK

### 🔧 How to Run From Scratch
```bash
npm create vite@latest contextapi -- --template react
cd contextapi
npm install firebase
# create context and wrap <App />
npm run dev
```
