## React + Firebase: Realtime Database

Read and write data using Firebase Realtime Database.

### 🚀 How to Run
```bash
cd 06-Firebase/07-realtimedb/realtimedb
npm install
npm run dev
# build & preview
npm run build
npm run preview
```

## 🎯 Summary & Purpose
Use Realtime Database to sync data instantly across clients.

### 📘 What I Learned
- Initializing and writing/reading nodes

- Structuring data for realtime apps

### 🧰 Technology Used
- React, Vite
- Firebase Realtime Database

### 🔧 How to Run From Scratch
```bash
npm create vite@latest realtimedb -- --template react
cd realtimedb
npm install firebase
# use getDatabase, ref, set, onValue
npm run dev
```
