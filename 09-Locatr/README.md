## Locatr (Geolocation Demo)

Express app with simple UI using EJS and Socket.IO.

### 🚀 How to Run
```bash
cd 09-Locatr
npm install
node app.js
```

## 🎯 Summary & Purpose
Share location data and render updates on the client in realtime.

### 📘 What I Learned
- Working with geolocation data on client and server
- Emitting events and handling updates with Socket.IO
- Rendering markers/updates in a simple UI

### 🧰 Technology Used
- Node.js
- Express.js
- EJS
- Socket.IO

### 🔧 How to Run From Scratch
```bash
npm init -y
npm install express ejs socket.io
echo "/* express + ejs + socket.io locatr skeleton */" > app.js
```
