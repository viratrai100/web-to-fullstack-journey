## Node.js File System Exercises

Simple Node.js scripts to practice file system operations like reading, writing, copying, and working with paths.

### 🚀 How to Run
- Open terminal and run:
```bash
cd 07-Backend/02-node.js-file_system
npm install
node script.js
```

## 🎯 Summary & Purpose
Practice basic file operations in Node.js to understand the core `fs` module and work with files and folders.

### 📘 What I Learned
- Difference between synchronous and asynchronous `fs` methods
- Reading, writing, appending, and deleting files
- Creating folders and working with relative/absolute paths
- Basic error handling and using `path` utilities

### 🧰 Technology Used
- Node.js
- Built‑in `fs` and `path` modules
